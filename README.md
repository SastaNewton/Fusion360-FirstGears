# Fusion360-FirstGears
# My First Fusion 360 Design

This repository contains my first CAD design created in Autodesk Fusion 360.

# Overview
This model is a 1:2 gear ratio, gear model.  
I created it to practice CAD modeling and improve my design workflow.

# Software Used
- Autodesk Fusion 360

# Files Included
- Source Fusion file (`.f3d`)
- STEP export (`.step`)
